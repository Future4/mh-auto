# 官方桌面版（Windows）资源覆写目录

本目录用于存放「Windows 官方桌面版客户端」专属的 pipeline 覆写与图片模板。

- 加载顺序：`resource/base` 在前，本目录在后；同名节点 / 同名图片会被本目录覆盖。
- 桌面版与手游 UI 基本一致时无需任何文件；只有当某个任务在桌面版上识别失败、
  需要单独调整坐标（roi/target）或替换模板图时，才在这里新增同名覆写。
- 图片模板放在 `desktop/image/` 下并保持与 base 相同的相对路径，即可自动覆盖。

示例：若 base 中节点「打开帮派界面」的 roi 在桌面版上偏移，可在
`pipeline/` 下新建 json 写入同名节点，只保留需要修改的字段即可。
