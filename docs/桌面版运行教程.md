# 桌面版教程（Windows 官方客户端）

本教程适用于「不装模拟器、直接用网易官方《梦幻西游手游》桌面版」的运行方式。
桌面版只有 Windows 版（Win7 及以上），Mac 用户请走 PlayCover 或模拟器方案。

> 免责提醒：官方桌面版带网易反作弊机制，第三方自动控制工具存在被检测、封号的风险，
> 请自行评估后使用，本项目仅供学习交流。

## 1. 电脑设置（与模拟器方案相同）

1. 电脑缩放比例设为 100%（影响文字识别）。
2. 安装 [vc_redist](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
3. 安装 [.NET 10](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。

## 2. 游戏客户端设置

1. 从官网下载安装《梦幻西游手游》桌面版并登录进入游戏。
2. **把游戏窗口调成 16:9 横屏比例**（推荐客户区 1280x720 或 1920x1080）。
   项目启动任务时会检查画面比例，不是 16:9 会直接停止任务。
3. 关闭活动中右上角的眼睛（同模拟器方案）。

## 3. 启动本项目

### 方式 A：Release 包（推荐测试用）

1. 从 [Release 页](https://github.com/gitlihang/Maa_MHXY_MG/releases) 下载最新的
   Windows x64 压缩包（MFAAvalonia 版），解压。
2. 把本项目改动后的以下内容**覆盖**到解压目录：
   - `interface.json`
   - `resource/` 整个文件夹
   - `agent/` 整个文件夹
3. 先打开桌面版客户端并进入游戏主界面。
4. 双击运行 `Maa_MHXY_MG.exe`（即 MFAAvalonia 主程序）。
5. 在主界面中：
   - 控制器选择「**官方桌面版**」（Win32）；
   - 窗口选择下拉框中选中梦幻西游的窗口（按标题"梦幻西游"匹配）；
   - 资源选择「**官方桌面版**」。
6. 首次使用建议先单独运行「**帮派签到**」测试，确认截图与点击都正常再跑其他任务。

### 方式 B：源码运行（开发者）

1. 安装 Python 3.11+（安装时勾选 Add to PATH）。
2. 完整克隆项目（含子模块）：`git clone --recursive <仓库地址>`。
3. 安装依赖：`pip install -r requirements.txt`。
4. 下载 [MaaFramework Release](https://github.com/MaaXYZ/MaaFramework/releases)
   的 win-x64 包，解压到项目 `deps` 文件夹。
5. 执行 `python ./tools/configure.py`，再执行 `python ./tools/install.py v0.0.1 win-x64`。
6. 用 MaaPiCli 或 MFAAvalonia 指向 `install` 目录启动。

## 4. 常见问题

### 4.1 窗口下拉框里找不到游戏窗口

- 确认桌面版已打开且未最小化。
- 游戏窗口标题需包含"梦幻西游"。若实际标题不同，修改 `interface.json` 中
  Win32 控制器的 `win32.window_regex` 为正则表达式即可；
  也可以用 `win32.class_regex` 按窗口类名匹配。

### 4.2 截图黑屏 / 点击无效

桌面版是 DirectX 渲染，默认截图或输入方式可能不适用。在 `interface.json` 的
Win32 控制器里显式指定方式后重启程序再试：

```json
"win32": {
    "window_regex": "梦幻西游",
    "screencap": "FramePool",
    "mouse": "SendMessage",
    "keyboard": "PostMessage"
}
```

- 截图方式可尝试：`FramePool`、`DXGI_DesktopDup`、`PrintWindow`、`ScreenShot`
- 鼠标方式可尝试：`SendMessage`、`PostMessage`、`SendMessageWithCursorPos`、`MouseEvent`、`SendInput`

具体取值说明见 MaaFramework 的「控制方式说明」文档。

### 4.3 提示权限不足 / 无法控制

游戏若是以管理员身份运行的，控制程序也必须用管理员身份运行：
右键 `Maa_MHXY_MG.exe` → 以管理员身份运行。

### 4.4 提示缺少 Win32 控制单元（MaaWin32ControlUnit）

从 [MaaFramework Release](https://github.com/MaaXYZ/MaaFramework/releases)
下载同版本 win-x64 包，把其中的 `MaaWin32ControlUnit.dll`
复制到本程序的 `runtimes/win-x64/native` 目录后重启。
（本项目打包脚本已修复，后续新版本 Release 会自带该文件。）

### 4.5 任务跑到一半识别失败

桌面版与手游模拟器画面存在细节差异，部分模板/坐标可能失配。
请记录下日志中失败的节点名称并反馈，我们会在
`resource/desktop/` 目录中做桌面版专属覆写，不影响模拟器用户。

## 5. 已知限制

1. **多开暂不建议**：Win32 按窗口标题正则匹配，多个同名游戏窗口只会连接其中一个。
2. 69 级以下账号的兼容性问题与模拟器方案一致。
3. 被游戏最小化或完全遮挡时，部分截图方式会失败，请保持窗口可见。
